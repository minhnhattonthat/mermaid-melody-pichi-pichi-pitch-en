# Style reference

## Voice
- Lyrics: the songs of the anime's idol mermaids. Bright, hopeful, a little dreamy. Short lines, simple words a
  young reader knows, present tense, "you"/"I"/"we" as in the Japanese (キミ/ボク -> you/I, ボクら -> we).
- UI: friendly and short, like a kids' game talking to the player. Exclamation marks where the Japanese has them.
- Link-cable messages: clear and calm ("Checking the link connection...").
