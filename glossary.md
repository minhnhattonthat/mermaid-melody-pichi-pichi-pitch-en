# Glossary - Mermaid Melody Pichi Pichi Pitch (GBA, Konami 2003)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.
Kept game-neutral where possible so the sequel (Pichi Pichi Party, sibling repo) can reuse it.

## Rulings (pre-approved by the user, 2026-10)
- Honorifics: dropped; convey closeness through register. ねーちゃん/にーちゃん -> "Sis"/"Bro" style address.
- Name order: Western (given name first).
- Romanisation source: official English localisation (Del Rey manga / English dub) where it exists, else modified Hepburn.
- Credits: translated to English. Japanese staff names romanised in Western order (best effort; flag uncertain readings).
- Graphics text (title, menus, banners, buttons): in scope, all of it.
- Abbreviations: none; full names and terms everywhere, engine work before shortening.
- Song titles: official English titles are kept as they are (Legend of Mermaid, Super Love Songs!, Ever Blue,
  Splash Dream, Star Jewel); Japanese song titles are translated (see Songs).
- Lyrics: translated to English so the meaning comes across; keep the line split of the original, keep English
  phrases that are already English in the original (e.g. "Dear My Songs", "Super Live", "Splash Dream").
- No ordinal suffix glued to a number the game prints.

## Style rules
- Punctuation: 「」 -> "...", 『』 -> '...', … -> ..., ！ -> !, ？ -> ?, ～ around subtitles -> ~ or a dash.
- UI messages: short, friendly, imperative ("Choose a song!"). The game talks to young girls: warm, light tone.
- Multiplayer: つうしん = "link" (Link Cable); つうしんケーブル = "Game Link Cable".
